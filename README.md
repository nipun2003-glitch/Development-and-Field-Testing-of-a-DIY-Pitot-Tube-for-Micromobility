This project explores the design, fabrication, and field testing of a custom-built Pitot-static tube for electric scooters. Using accessible materials—such as PVC piping, silicone tubing, and a repurposed sauce bottle cap—we engineered a sensor that isolates dynamic pressure to calculate true airspeed utilizing Bernoulli's principle. To accommodate the scooter's unique geometry, the system features a custom 108° mounting angle that offsets the steering stem rake, ensuring the forward boom remains perfectly horizontal to incoming airflow. Paired with a PCE-HVAC 2 digital manometer, the DIY setup successfully demonstrated highly accurate airspeed measurements during initial field tests near 20 km/h
